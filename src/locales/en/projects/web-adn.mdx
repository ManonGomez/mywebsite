## The context

A collaboration with the Web ADN agency across multiple client projects, each with different technologies, functional constraints and visual identities.

## My contribution

I implemented several designs with pixel-perfect precision, ensuring visual fidelity, responsive layouts and consistent behaviour across browsers and screen sizes.

I developed custom PHP and JavaScript features, working directly on the projects' application logic.

Part of my work involved fully custom WordPress architectures: using the CMS core without a page builder or generic theme, with custom editorial components and content blocks. These blocks let administrators build pages that follow the defined design system.

This collaboration required regularly switching between projects, quickly understanding existing codebases and adapting my work to each client's constraints.
